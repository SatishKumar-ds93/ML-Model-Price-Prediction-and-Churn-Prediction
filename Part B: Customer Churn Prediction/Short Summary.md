## Short Summary of the Project

This project develops an end-to-end Customer Churn Prediction system using Machine Learning to identify customers who are likely to leave the company. The analysis included data cleaning, exploratory data analysis, feature engineering, correlation analysis, preprocessing, and handling class imbalance using SMOTE. Three models—Logistic Regression, Random Forest, and XGBoost—were developed and hyperparameter-tuned using cross-validation. Tuned XGBoost was selected as the final model, achieving 77.00% **accuracy,** 55.19% **precision,** 71.12% **recall,** 62.15% **F1-score**, and 84.08% **ROC-AUC**. The analysis identified factors such as month-to-month contracts, short tenure, fiber-optic service, electronic-check payments, and lack of online security/technical support as important churn-related signals. The project also includes a new-customer prediction system that estimates churn risk and can support targeted customer-retention strategies
