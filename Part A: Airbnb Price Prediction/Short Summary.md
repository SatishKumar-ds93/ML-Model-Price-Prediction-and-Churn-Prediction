## Short Summary of the Project

This **Airbnb Price Prediction** project develops Prototype an Interactive Development Environment (IDE) Machine Learning regression solution to estimate Airbnb listing prices. The project covers data cleaning, EDA, outlier handling, feature engineering, preprocessing, model comparison, and hyperparameter tuning using Linear Regression, Random Forest, and Gradient Boosting. The tuned **Gradient Boosting Regressor** was selected as the final model, achieving **R²** = 0.5533, **RMSE** = 0.4374, and **MAE** = 0.3359. The trained pipeline was saved and integrated with a **Streamlit application**, allowing users to enter listing details such as property type, room type, neighbourhood, reviews, and amenities to receive an estimated nightly price, demonstrating how Machine Learning can support data-driven Airbnb pricing decisions.
